03 — Работы

Проекты

01 — SAAS
ScrewSec
SaaS-сервис для российского малого бизнеса: автоматическая генерация политик информационной безопасности под 152-ФЗ и ГОСТ Р 57580. Пользователь заполняет 13-вопросный конструктор — система генерирует готовый документ через LLM. Сайт задеплоен на Yandex Cloud (Object Storage + Cloud Functions), LLM-бэкенд на Cloudflare Workers AI, контактная форма через Telegram Bot API. Реализована SHA-256 аутентификация, CSP, защита от prompt injection, PDF-экспорт.
Live Cloudflare AI Yandex Cloud Telegram Bot SHA-256

02 — AUTOMATION
Trading Signal Bot
Полная система оценки торговых сигналов из Telegram-каналов. Telethon парсит каналы и шлёт вебхуки в n8n, где Groq (llama-3.1-8b) классифицирует сигналы. Оператор получает карточку сигнала с кнопками подтверждения, подписчикам уходят уведомления. Параллельно paper_trader.py симулирует виртуальные сделки с трекингом MFE/MAE и уведомлениями по цепочке ответов. Роль-система оператор/клиент, защита от дублей, авто-подтверждение, /positions с реальными данными Bybit Demo.
Python Telethon n8n Groq LLM Bybit API

03 — BOT
Backtesting System
Отдельный модуль для ретроспективного анализа: Telegram-бот принимает один сигнал и возвращает результат с графиком свечей (matplotlib). Массовый режим прогоняет всю историю из Google Sheets и генерирует отчёт по каналам. Нормализация тикеров, fallback с linear на spot, кэш парсингов Groq для экономии API-лимитов, отчёты в Markdown для Obsidian и CSV.
