Кто я

Выбери, насколько подробно рассказать.

TIM://aboutДЛЯ ТЕХЛИДА
Стек, подход, как я пишу код.

Основной язык Python. Для Telegram беру aiogram и Telethon, для сети aiohttp и httpx, фоновые задачи держу на APScheduler. Храню данные в SQLite и Google Sheets.

LLM встраиваю как деталь с ограничениями, а не как магию: Groq, Cloudflare Workers AI, vision-модели. Машинный текст всегда помечен, чтобы его не спутали со словами человека.

Деплою на Linux: systemd, nginx, bash. Из облаков работал с Yandex Cloud и Cloudflare. Если логика трогает деньги, перед изменением гоняю офлайн-selftest и тесты с моками сети.

КОММЕРЧЕСКИЙ ПРОЕКТ

Торговая система сигналов

Превращает сообщения из Telegram-каналов в сделки на бирже. Решение о сделке принимает человек-оператор.

КОНВЕЙЕР // 7 ЗВЕНЬЕВ
  1. Telegram-каналытекст + скриншотыИСТОЧНИК
  2. ПарсерTelethonСБОР
  3. Vision-модельтекст с картинокOCR
  4. n8n + LLMGroqРАЗБОР
  5. Реестр сигналовGoogle SheetsДАННЫЕ
  6. Оператор-боткарточка + кнопкиЧЕЛОВЕК
  7. Биржа Bybitdemo · real по флагуИСПОЛНЕНИЕ
  • LLM переводит свободный текст автора в структуру: пара, направление, вход, стоп, тейки.
  • Скриншоты тоже идут в разбор: vision-модель переписывает текст с картинки под явной пометкой. Так описание графика не превращается в выдуманную сделку.
  • Оператор получает карточку сигнала и подтверждает кнопкой. По умолчанию всё идёт на demo-счёт, реальный подключается только явно.
  • Симулятор ведёт виртуальные сделки с MFE/MAE. Бэктест прогоняет историю по каналам, рисует свечные графики и собирает отчёты.
  • 4 systemd-сервиса на сервере, 34 модуля тестов.
